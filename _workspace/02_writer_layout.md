| | **변형 A · 로컬 디렉터리 배치** | **변형 B · 모노레포 (002 단계 4)** |

## 1. 003 §2-3 의 "앞당기지 말라" 근거 3개는 A 에 적용되는가 — **적용되지 않는다 (확인)**

과제가 요구한 판정이다. 결론부터: **3개 전부 B 를 겨냥한다.** 실측 근거를 붙인다.

| # | 003 §2-3 의 근거 | A 에 적용되나 | 근거 |
|---|---|---|---|
| **1** | B2 는 되돌리기 비용이 가장 높다 — 실서비스 2개의 **배포 파이프라인 동시 재설계**, **릴리즈 격리 상실**(002 Q2 미결) | **아니오** | **M4.** 두 저장소 `rsync`/`scp`/`ssh` hit **각 0건**. 배포는 `GitHub Release → deploy.yml → appleboy/ssh-action → 서버가 GitHub 에서 직접 fetch`. 로컬 머신은 배포 경로에 **등장하지 않는다**. 서버 경로는 `secrets.DEPLOY_PATH`(fin) / `/home/nasty68/myFitness` 하드코딩(fit) — **둘 다 서버 파일시스템 기준**. 로컬에서 배포에 닿는 유일한 접점은 `git push` + Release 생성이고 **cwd 가 저장소 안이기만 하면 절대경로 무관**. 릴리즈 격리는 저장소·원격·태그가 분리된 채 남으므로 **상실 사유 자체가 없다** |
| **2** | 잘못된 추상화가 **3방향으로 전파**된다 — 두 앱이 한 트리에 있으면 즉시 퍼진다 | **아니오** | **M6 + M5.** 양쪽 `package.json` `workspaces` **null**, `pnpm-lock`/`yarn.lock`/`.npmrc` **0**, lockfileVersion 3 각자 → **npm 이 상위를 올려다볼 여지가 없다**. ### 1-1. 그러나 — **"A 는 공짜"라는 결론은 나오지 않는다**

003 §2-3 이 A 에 적용되지 않는 이유는 **A 가 싸서가 아니라, §2-3 이 A 를 검토한 적이 없어서다.**
A 에는 §2-3 이 열거하지 않은 **별개의 비용 축**이 있고, 그게 §3 이다 —
`~/.claude/projects/` 경로 키잉. 003 §2 는 모노레포 질문에 답하느라 이 축을 보지 않았다.

### 1-2. 그리고 — **A 는 B 의 선행 단계가 아니다** (주의 표시)

A 를 해도 B 의 청구서는 줄지 않는다. B 의 비용 본체는 **배포 파이프라인 재설계 · 릴리즈 격리 ·
git 이력 병합**인데 A 는 셋 중 어느 것도 건드리지 않는다(M4 · 저장소 3개 유지).
오히려 B 로 갈 때 `repos/myFinance` → `apps/finance` 로 **경로를 한 번 더 옮기고**,
§4 의 pleiades 쪽 참조 12곳을 **두 번 고친다**.

→ **A 는 자기 이득(세션 편의)으로만 정당화되어야 한다.** "모노레포로 가는 계단"이라는 근거로
정당화하면 003 §2-3 을 우회해 B 를 앞당기는 것과 같아진다.

## 3. 정면으로 다룰 비용 — 세션·메모리가 **절대 경로로 키잉**된다

이것이 A 의 유일한 큰 비용이고, **`mv` 로 막을 수 없는 유일한 항목**이다.

```
~/.claude/projects/-Users-sagan-workspace-myFinance/   113 MB · 세션 7 · memory 38
~/.claude/projects/-Users-sagan-workspace-myFitness/   141 MB · 세션 6 · memory 18
~/.claude/projects/-Users-sagan-workspace-pleiades/    6.4 MB · 세션 2 · memory 4
```

키 9개 전수 검사에서 **키 ≠ cwd 경로 파생 사례 0건** (`/`→`-` 치환, `_` 보존).
이동하면 키가 `-Users-sagan-workspace-pleiades-repos-myFinance` 로 바뀐다.

| | |
|---|---|
| **A-mv 에서 발생하나** | **예** |
| **A-clone 에서 발생하나** | **예 — 동일** |
| 왜 `mv` 가 못 막나 | 1위 리스크(gitignored 파일·로컬 커밋 소실)는 `mv` 가 전부 막지만, 이 축은 **경로가 바뀐다는 사실 자체**에서 온다. `mv` 도 경로를 바꾼다 |

> `docs/research/claude-code-mechanisms.md:31-33` 은 `<project>` 가 *"git 저장소 기준으로 파생"*
> 이라 적었다. 두 저장소는 이동 후에도 각자 git 저장소이므로 그 규칙도 성립하지만,
> **어느 규칙이든 결과는 경로 문자열**이고 그 경로가 바뀐다. 결론은 같다.

### 3-1. 완화안 — **전부 미확인. 확정적으로 쓰지 않는다**

| | 완화안 | 대상 범위 | 상태 |
|---|---|---|---|
| (a) | 이동 후 `~/.claude/projects/<구 키>` 디렉터리를 **새 키 이름으로 `mv`** | memory + 세션 `.jsonl` 둘 다 (성공한다면) | **실증 미측정** — 감사가 검증 중 |
| (b) | 각 저장소 `.claude/settings.json` 에 **`autoMemoryDirectory` 절대 경로 고정** | **memory 만.** 세션 `.jsonl` 13개 / 254 MB 는 설계상 이 설정의 대상이 아니다 (`claude-code-mechanisms.md:30-40`) → **기껏해야 부분 완화** | **실증 미측정** |
| (c) | 구 경로에 **심링크**를 남겨 키를 보존 | 세션 시작 시 cwd 가 논리 경로로 잡히느냐 물리 경로로 잡히느냐에 전적으로 달림 | **미측정 · 이 문서가 새로 제기** |

**어느 것도 "된다"고 쓰지 않는다.** 감사 결과가 나오기 전까지 §5 의 권고는 **이 완화가 실패해도
성립하는 형태**로 적었다.

### 3-2. 여기서 도출되는 사용자 판단 — **Q16**

완화안이 성공하든 실패하든, **그 전에 정해야 할 것이 있다.** 두 저장소가 pleiades 하위로 오면
앞으로 세션을 **어느 키로 열 것인가**. 완화 작업의 목표 자체가 여기서 갈린다. → §6 Q16.

### 옵션 2 · A-clone — 새로 `git clone`

```bash

git clone <fit remote> ~/workspace/pleiades/repos/myFitness
```

**clone 으로 따라오지 않는 것 — 전수 (M1)**

| 소실 항목 | 저장소 | 규모 | git 어디엔가 있나 |
|---|---|---|---|
| **`.claude/` 하네스** | **myFitness** | **18 파일 / 104 K** (agents 5 + rules 3 + skills 9 + settings.local) | **아니오 — `.gitignore` 에 `.claude/`** |
| **`CLAUDE.md`** | **myFitness** | 8,621 B | **아니오 — `.gitignore` 에 `CLAUDE.md`** |
| `.env` | 양쪽 | fin 332 B (키 7) / fit 221 B (키 4) | 아니오 |
| `.garmin-tokens/` | myFitness | 2 파일 / 8 K | 아니오 (또는 Garmin 재인증) |
| `.claude/settings.local.json` | myFinance | 17,469 B (allow 150) | 아니오 |
| origin 에 없는 커밋 **3개** | fin `feat/45-error-loading` 1 · fit `fix/261-2` 2 | — | **아니오** |
| `integration/pleiades` 브랜치 이름 2개 | 양쪽 | 커밋 0개 (04) | 이름만 재생성 가능 |
| 로컬 태그 | — | **0개** | — |

**비대칭이 핵심이다.** `git -C myFinance ls-files .claude | wc -l` = **16**,
`git -C myFitness ls-files .claude | wc -l` = **0**.
→ **myFinance 는 clone 하면 하네스가 따라오고, myFitness 는 통째로 소실된다.**

**`.env` 는 example 로 못 메운다.** myFinance `.env` 에만 있고 `.env.example` 에 없는 키
**`NEXTAUTH_SECRET`, `NEXTAUTH_URL` 2개**. `cp .env.example .env` 하면 **조용히 빠진다** —
실행해봐야 안다. (myFitness 는 0개.)

| | |
|---|---|
| 디스크 | 즉시 +59.5 MB → `npm ci` 후 +1.65 GB → build 후 **+3.06 GB**. 여유 21 GiB(capacity **98%**) → 약 18 GiB |
| 여기서 멈추면 남는 것 | 같은 저장소가 **두 벌**. 어느 쪽이 정본인지 사람이 기억해야 한다. 시크릿도 두 벌 |

**A-clone 은 A-mv 에 지배된다(dominated).** A-clone 의 유일한 장점 — *"원본을 안 건드린다"* —
은 A-mv 의 되돌리기가 `mv` 2회라는 사실로 상쇄된다. 그 대가로 3.06 GB · 수동 복사 6종 ·
조용한 실패 경로 1개를 산다. **사용자가 "클론"이라고 말했지만, 그 단어가 지시하는 결과는 `mv` 로 더 싸게 온다.**

## 5. 권고 — **옵션 1 (A-mv), 단 Q16 선행 · 1a 착수 전 또는 1a 완료 후**

### 근거

1. **사용자가 요청한 결과("pleiades 가 두 프로젝트를 하위에 둔다")를 가장 싸게 달성한다.**
   A-clone 이 주는 것 중 A-mv 가 못 주는 것은 없다(§4 옵션 2 지배 논증).
2. **되돌리기가 `mv` 2회다.** 디스크 0, 소스 변경 0, 서버 무관.
3. **배포를 깨지 않는다** — M4 가 이 측정에서 가장 확실한 결론이다.
4. **1a 와 독립이다.** 003 §5 의 1a-0~1a-4 는 전부 저장소 내부 작업이고 배치에 의존하지 않는다.

### 권고에 붙는 조건 3개

| # | 조건 | 왜 |
|---|---|---|
| **C1** | **Q16(세션 키 정책)에 먼저 답한다** | 이동 자체보다 *이동 후 무엇을 하느냐*가 memory 56개·세션 254 MB 의 운명을 정한다. 답 없이 옮기면 그 결정을 **암묵적으로** 내리는 것이 된다 |
| **C2** | **`.gitignore` 에 `repos/` 를 이동 *전에* 추가한다** | M5 실증대로 방치 시 gitlink 커밋. 순서를 바꾸면 사고 후 정정이 된다 |
| **C3** | **1a 착수 *전* 또는 1a 전체 완료 *후* 에 한다. 도중은 안 된다** | 도중이면 ① `04_operator_rollback.md` 의 경로가 진행 중에 무효화되고 ② 그 작업의 세션 이력이 두 키로 쪼개진다. 003 §5-2 의 단계별 되돌리기는 배치와 무관하므로 **미루는 비용은 `--add-dir` 재지정뿐** |

### 권고하지 않는 것

- **A-clone** — §4 옵션 2. 하려면 최소한 `mv` 로 하라는 것이 이 문서의 답이다.
- **submodule** — M5: `.gitignore` 한 줄로 충분하고, submodule 은 커밋 SHA 핀·`--recurse-submodules`
  를 만들어 **"독립 저장소 유지"라는 A 의 전제를 깬다.** (사용자 판단 불필요 · 구현 결정)
- **원본 디렉터리 삭제** — A-mv 를 택하면 원본은 애초에 없다. A-clone 을 택했다면
  **감사·Q16 이 끝날 때까지 원본을 지우지 않는다.**

### 이 권고가 뒤집히는 조건

| 조건 | 어떻게 바뀌나 |
|---|---|
| 감사가 완화안 (a)·(b)·(c) **전부 실패**로 판정 | memory 56개·세션 254 MB 를 **버리는 것**이 이동의 실가격이 된다. 그 값이 `--add-dir` 재지정 편의보다 크면 **옵션 0(현상 유지)이 답**이 된다 |
| Q16 이 "(가) pleiades 단일 키"로 답해지고, 루트 세션에서 하위 `.claude/` 자동 탐색이 **안 되는 것으로 확인**되면 | 두 저장소 하네스(fin agents 4/skills 7/rules 5 · fit agents 5/skills 9/rules 3)를 pleiades 로 **이식**하는 작업이 이동에 딸려온다 — 지금 청구서에 없는 항목 |
