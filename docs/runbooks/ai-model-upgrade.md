# AI 모델 교체 — 고정 모델을 바꾸는 유일한 경로 (#255)

**왜:** 2026-10-23 서버 CLI 가 자동 업데이트(2.1.273 → 2.1.308)되면서 `--model sonnet`·`haiku` 별칭이 다른 모델을 가리켰고, fin 브리핑·리뷰가 후퇴했다(#247 판정). 검색 자체는 정상이었고 새 모델이 문체·"추측 금지" 해석을 바꿨다. 그래서 두 앱은 **등급(haiku · sonnet)만 고르고 실제 모델 ID 는 고정**한다.
**원칙:** 모델은 더 나은 것으로 옮겨 간다(haiku < sonnet < opus · 같은 등급의 새 버전). **단 답변이 후퇴하는 교체는 하지 않는다** — 교체는 이 절차의 비교와 사용자 판정을 통과한 PR 로만 한다.
**누가:** 비교 실행 중 서버 단계는 사용자(Claude 서버 무접촉 · I-3). 코드·PR·판정 기록은 Claude. **판정은 사용자.**

## 고정 위치

| 앱 | 단일 출처 | 고정 | 호출부 |
|---|---|---|---|
| fin | `apps/finance/src/lib/ai/models.ts` `PINNED_MODELS` | 등급 → ID · 자식 env(`ANTHROPIC_DEFAULT_HAIKU_MODEL` · `ANTHROPIC_DEFAULT_SONNET_MODEL`) | `askAdvisor` 1곳 — 등급은 호출부 `model:` 또는 `intent`(`pickModel`) |
| fit | `apps/fitness/src/lib/ai/models.ts` `PINNED_CLAUDE_MODELS` | 같음 | claude 실행 7곳 — 소스 검사 테스트(`models.test.ts`)가 별칭 직접 사용·env 누락을 막는다 |

자식 env 는 `--model` 로 고정되지 않는 **CLI 내부 보조 호출**(WebSearch 요약 등 — 10/23 A/B 에서 함께 바뀌었다)을 막는다.
실제 쓴 모델은 CLI result 의 `modelUsage` 로 확인한다 — fin 은 매 호출 `[advisor] ok … used=<ID들>` 로그, 두 앱 모두 고정값과 다르면 **`모델 드리프트`** 경고.

## 언제 이 절차를 타나

| 계기 | 비고 |
|---|---|
| 같은 등급의 새 버전이 나왔다 | 서두르지 않는다 — 비교가 먼저 |
| 등급 승격(haiku → sonnet → opus)이 필요하다 | 비용이 오른다 — 예산 한도(아래)를 함께 다시 정한다. **opus 는 등급 타입에 아직 없다**(코드 변경 포함) |
| 고정 모델의 지원 종료가 공지됐다 | 종료 **전에** 끝낸다 — 종료되면 호출이 API 오류로 실패하고 advisor 모니터가 연속 실패를 알린다 |
| 로그에 `모델 드리프트` 경고가 났다 | 교체 계기가 아니라 **조사 대상**이다. CLI 가 고정 ID 를 다르게 해석했거나 보조 모델이 새 경로로 바뀐 것 — 이슈로 기록하고 원인을 본다 |

## 1. 이슈

pleiades 이슈 하나: 후보 모델 ID · 바꿀 등급(또는 호출부) · 계기 · 비용 변화 예상. 라벨 `fin`/`fit`.

## 2. 비교 (서버 · 사용자 실행)

현행 ID 와 후보 ID 로 **같은 질의를 같은 시각에** 돌려 나란히 본다. 시각이 다르면 뉴스·시세가 달라 비교가 안 된다.
대표 질의 — 호출 경로마다 최소 1건:

| 앱 | 질의 | 출처 |
|---|---|---|
| fin | 한국장·미국장 모닝 브리핑 | `src/bot/notifications/briefing.ts` `buildBriefingPrompt` |
| fin | 한국장·미국장 클로징 리뷰 | `src/bot/notifications/active-review.ts` |
| fin | TA 가이드(haiku) | `src/bot/notifications/ta-signal-alert.ts` 의 가이드 프롬프트 |
| fin | 커스텀 전략 파서 · `/ai` 자유 질문 1건 | `src/lib/custom-strategy/parser.ts` · 봇 `/ai` |
| fit | 어드바이저 질문 · 영양 추정(텍스트) · 검진 추출 | `src/lib/ai/claude-advisor.ts` · `src/lib/nutrition/*` · `src/lib/checkup/import/extract.ts` |

공통 플래그는 각 호출부의 인자 그대로(`--tools` · `--allowedTools` · `--permission-mode` · `--strict-mcp-config` · MCP 설정). **자식 env 의 두 키도 후보 ID 로** 맞춘다 — 안 그러면 보조 모델은 현행으로 남는다. `DISABLE_AUTOUPDATER=1` 을 붙여 비교 도중 CLI 가 바뀌지 않게 한다.
비교 실행 자동화(대표 질의 세트를 두 ID 로 돌려 나란히 저장하는 스크립트)는 후속이다 — 그 전에는 위 표를 손으로 돌린다.
