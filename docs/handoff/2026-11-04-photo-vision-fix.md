- **운영 사진은 R1 배포 전까지 계속 실패한다.** #463 은 `dev` 에만 있다.
- **원인 실측 범위:** 음식 사진을 줄인 JPEG 기준, `@경로` 는 200 KB 까지 인식 · 498 KB 부터 못 봄(크기별 2회 · CLI 2.1.308). 정확한 경계와 CLI 내부 원인은 재지 않았다. 버전 차이는 원인이 아니다.
- **본문 전달 실측 범위:** 음식 사진 1장(3.1 MB)은 사진과 맞는 항목을 냈다. 그 밖에는 단색·노이즈 JPEG·PNG 로 9.6 MB 까지 인식을 확인했다. 큰 WebP 는 시험하지 않았다.
- **아직 안 본 경로:** Discord 첨부 → 저장 전체(단위 테스트만) · 웹 음식 사진 업로드 · 텔레그램 경로 · 실제 결과지와 결과지 화면 업로드(가짜 표로만 시험). 결과지 기능이 운영에서 실패한 기록을 본 것은 아니다.

## 재현이 필요한 절차

- **zsh 종료 코드:** 이 환경 셸은 zsh 라 `${PIPESTATUS[0]}` 가 비어 나온다. 8절 판정은 `bash -c` 안에서 `$?` 로 받는다.
- **실제 CLI 로 함수 호출:** 임시 스크립트를 앱의 ignored `logs/` 에 두고 `CLAUDE_BIN=<스크래치 CLI> DISABLE_AUTOUPDATER=1 npx --no-install tsx logs/<파일>.ts`. DB·Discord 를 거치지 않는다. 끝나면 지운다.
- **과거 버전 CLI:** 스크래치에서 `npm install @anthropic-ai/claude-code@<버전>`.
- **`.server-scripts/` 시험:** 서버 전용 가드는 `PLEIADES_SCRIPT_TEST=1` 로 넘고, 경로는 env(`FIN_ROOT` 등)로, `pm2` 는 PATH 스텁으로 바꾼다.
