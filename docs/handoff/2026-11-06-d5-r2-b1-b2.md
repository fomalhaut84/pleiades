## 주의사항

- **세션 시작 때 현재 상태를 다시 본다.** 이 노트보다 `git log` · `gh pr list` 가 정본이다. 이 세션 끝의 관측: `dev` = `ba760f9` + 이 노트의 PR · 운영 `v1.8.1`.
- **동결:** B 묶음 머지 중에는 릴리즈 PR 을 열지 않는다. 급한 수정은 `hotfix/` 로 낸다. B 묶음은 순서대로 머지한다.
- **B3 는 B2 패턴을 그대로 쓰면 된다.**
  - `register*` 블록 삭제: 중괄호 짝을 맞춰 지우는 스크립트. 세션 스크래치에 있었고 저장소에는 없다.
  - 대조표: 삭제 케이스를 `describe`/`it` 목록으로 뽑아 남는 테스트와 맞춘 뒤, 빈 칸 케이스를 decide 테스트로 옮긴다.
  - 사전 리뷰 focus 에 대조표를 고정하면 리뷰가 빈 칸을 찾아 준다(B2 에서 5개).
- **fit 테스트 실행:** `tools/local/run.sh fit -- npm run test` 등. zsh 에서는 `${PIPESTATUS[0]}` 가 비어 나온다. 종료 코드는 출력을 버리고 `$?` 로 본다.
- **`apps/*` 를 바꾸면 `deploy` 테스트(약 7분)도 돌린다.** CI 에 없다.
- **앱 lock 갱신:** `run.sh <app> -- npm install --package-lock-only --ignore-scripts`. 링크된 `packages/*` 의 버전 표기도 함께 따라잡는다(1.7.0 → 1.8.1). 정상이다.
