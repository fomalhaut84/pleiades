- 로컬 버튼 실측: 임시 스크립트를 앱의 ignored `logs/` 에 두어야 앱 의존성을 찾는다. `.server-scripts/` 에서는 `dotenv` 를 찾지 못했다. 없는 id 로 보내면 DB 쓰기가 없다.
