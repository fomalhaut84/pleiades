- **`grep` 옵션이 도구마다 다르다.** GNU `grep` → `--binary-files=text`, `git grep` → `--text`.
  후자에 전자를 쓰면 `unknown option` 으로 **실패한다** (실측 git 2.50.1)
- **`git grep <ref>` 는 출력에 `<ref>:` 접두사를 붙인다.** 경로 필터·집계 전에 `cut -d: -f2-` 로 벗겨야 한다.
  안 벗기면 누수 필터가 **17건 중 17건을 오탐**한다 (실측)
- **003 의 Q25~Q27 과 004 의 Q20~Q24 는 다른 질문이다.** 번호가 겹쳐 003 쪽을 Q25 부터로 재번호했다
