## 0. 한 줄 요약

**전환은 스위치가 아니라 새 배포 경로를 만드는 일이다**([S] W1 — pleiades 에는 태그·Release·배포 job 이 0). 권고 경로는
**① pleiades 루트에 새 배포 스크립트·pm2 정의를 만들고(`apps/*` 무수정) → ② 첫 릴리즈 → ③ 서버에 앱별 pleiades 체크아웃을 옛 서비스 디렉터리 옆에 두고 → ④ 앱 하나씩(권고 fin 먼저) "서비스 동결 → 서비스가 dev 를 먼저 릴리즈 → 마지막 수용 0 → 백업 → 옛 프로세스 정지 → 새 프로세스 기동" → ⑤ 관찰 기간 동안 옛 디렉터리·DB 를 그대로 두어 swap back 으로 되돌린다.**
DB 는 **기존 서비스 DB 를 그대로 쓴다**(데이터 이전 0). 첫 배포는 **플랫폼 키(Discord) 를 비워** 서비스와 같은 텔레그램 동작으로 들어가고, Discord 는 그 뒤 루트 `.env` 로 켠다.
**격리 불변식은 전환 집행 순간 그 앱의 서버 `.env` 범위에서만 풀린다** — pleiades 저장소·CI·로컬·Claude 세션의 격리는 그대로다(§6).

> **2회차 보강(감사 [A]).** "서비스가 dev 를 먼저 릴리즈" 는 **fit 에 필요하고 fin 은 마이그레이션 면에서 생략 가능**하다(⑱ · T-5a 직전 재측정). 서비스 실값(봇 토큰·DB·외부 계정)은 **T-5c ① 에서 처음** 서버 `.env` 에 들어간다(정정 6). 서비스 배포 경로 차단은 **T-5c 진입 조건**이다(정정 4). 마이그레이션은 첫 전환 실행에서 **돌리지 않고 `migrate status` 로 검사만** 한다(정정 5).

**마이그레이션 — 전환의 유일한 편도 원천:**

- 배포본은 서비스 `main`(최신 태그), `apps/*` 는 서비스 `dev` 다(⑥). **둘 사이에 마이그레이션 차이가 있으면 pleiades 첫 배포의 `prisma migrate deploy` 가 그것을 서비스 DB 에 적용한다.** ~~차이 크기는 미측정(M2 · U14).~~ → 지금 시점 두 앱 0 · fit 서비스 `dev` 에 1개 대기(⑱).
- Prisma 마이그레이션은 **forward-only** 다 — 적용 뒤 옛 코드로 swap back 하면 **옛 코드가 새 스키마 위에서 돈다.** 호환은 마이그레이션 내용에 달려 있고(미분석), 호환이 안 되면 되돌리기는 **전환 직전 백업 복원 = 그 뒤 데이터 손실 = 편도**다.
- **그래서 Q75 권고 F-1**: 전환 전에 **서비스가 자기 `dev` 를 먼저 릴리즈·배포**하게 한다(서비스 자신의 평상 운영 — pleiades 가 하지 않는다 · I-1). 그 뒤 마지막 수용 0 이면 **배포본 스키마 = `apps/*` 스키마** → 전환 첫 배포의 마이그레이션 차이 **0** → DB-a 롤백이 즉시로 남는다. ⑱ 기준 **fin 은 ②가 마이그레이션 면에서 불필요 · fit 은 필요**.
- **판정은 실행 전 읽기 전용 검사로 한다(정정 5).** `migrate deploy` 는 대기 마이그레이션을 **실행하면서** 알리므로 *"돌려 보고 0 이 아니면 중단"* 은 이미 적용된 뒤다. T-5c 에서 `npx prisma migrate status`(대기 · DB 에만 있는 마이그레이션 둘 다 보고 · 비0 종료) — 또는 `_prisma_migrations` 이름 집합 ↔ `apps/<app>/prisma/migrations` 디렉터리 비교 — 로 검사하고, **첫 전환 실행에서는 `migrate deploy` 를 빼고 검사만** 둔다.
  > **정정 (2026-10-20 · T-1d · #180).** 위 괄호 *"대기 · DB 에만 있는 마이그레이션 둘 다 보고 · 비0 종료"* 는 **반만 맞다** — prisma 6.19.3 실측: 대기는 rc 1 로 보고하지만 **DB 전용은 "up to date" · rc 0** 이다(measured-facts *2026-10-20 — T-1d 로컬 리허설* G-e). 그래서 "또는" 이 아니라 **둘 다** 쓴다 — `deploy/deploy.sh` 는 `migrate status` 뒤에 `public._prisma_migrations` ↔ 디렉터리 이름 대조를 psql 읽기 전용으로 한다(접속 정보는 env 로만 · `-X`). 되돌리기: 문구 (**즉시**).
- **006 Q61(전환 설계 전 스키마 무변경)은 전환 집행 + 관찰 기간이 끝날 때까지 연장한다**(Q74). pleiades 가 그 사이에 마이그레이션을 더하면 위 편도가 다시 생긴다.
