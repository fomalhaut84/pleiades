## 0. 한 줄 요약

**텔레그램을 끄는 일은 env 삭제가 아니라 세 겹의 코드 작업이다.** ① 봇 프로세스가 텔레그램 기동에 묶여 있어 토큰을 빼면 **Discord 알림·버튼·크론까지 함께 멈춘다**(L14) ② Discord 쪽은 지금 **버튼만 받는다**(L16) ③ 앱 핸들러가 grammY `Context` 에 직접 묶여 있다(L9). 그리고 **Discord 쪽 로컬 격리 가드는 지금 0 이다**(L27).
확정 경로는 **D-G 로컬 Discord 가드 + 검증 봇(C-9 · 사용자가 만든다) → D-0 공통 수신 계층 `packages/chat`(소비자 0) → D-1 텔레그램 없이도 뜨는 봇 프로세스 → D-2 fit 병행 → D-2′ fit 텔레그램 수신 끔 → D-3 / D-3′ fin → D-4 문구·프롬프트 → D-5 텔레그램 제거.**
**편도는 없다** — 텔레그램 봇은 지우지 않고 둔다(C-12). 단 **서버 토큰을 지운 뒤 되돌리기 바닥은 조건부로 D-1 태그**다(§6 머리).
